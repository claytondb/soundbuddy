# SoundBuddy

A programmable soundboard for quick audio playback.

## Features

- **Sound Grid** - Visual soundboard layout
- **Add Custom Sounds** - Upload your own audio files
- **Quick Presets** - Pre-configured sound banks
- **Master Volume** - Global volume control
- **Stop All** - Emergency silence button
- **Web Synth** - Built-in synthesizer (synth.js)

## Usage

1. Open `index.html` in a browser
2. Click "Add Sound" to upload audio files
3. Click sound buttons to play
4. Adjust volume with the slider
5. "Stop All" to silence everything

## Use Cases

- Streaming soundboard
- Podcast sound effects
- Gaming audio cues
- Presentation sounds
- Fun with friends

## Tech

- Web Audio API
- Built-in synthesizer
- Local storage for saved sounds
- Works offline after sounds are loaded

## Files

- `index.html` - Main interface
- `style.css` - Styling
- `app.js` - Main app logic
- `synth.js` - Synthesizer module
